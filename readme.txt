1. Download Zip lalu Ekstrak
2. Buka chrome://extensions, aktifkan Developer mode, lalu klik Load unpacked dan pilih folder \syuuunibautomation-master\syuuunibautomation-master\auto-fill-ext.
3. Buka halaman form, lalu klik ikon extension. Semua tab terisi otomatis.
4. Cari extension bernama Auto Fill Mid-Meeting Form dan klik Extension tersebut pada tab peer review.
